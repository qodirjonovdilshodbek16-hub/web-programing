About TechNest

TechNest is a demo electronics store built for the Web Programming final project. It is a multi-page website made with plain HTML, CSS and JavaScript — no frameworks — and hosted on GitHub Pages.

What it does

Browse 55 products, filter and sort, pick colors, add to cart, apply promo codes and complete a demo checkout.

How it's built

Semantic HTML, responsive CSS with light and dark themes, and vanilla JavaScript. The cart is saved in your browser's localStorage.

Honest by design

No fake reviews, ratings or sales. Prices are approximate list prices and images are original illustrations.

FAQ

Can I really buy something?

No. TechNest is a student project; no payments are processed and nothing ships.

Are the prices accurate?

They are approximate US list prices for base models and can differ from current retail prices.

Where is my cart stored?

Only in your browser (localStorage). Clearing site data empties it.

Which promo codes work?

STUDENT10 gives 10% off and FREESHIP gives free standard shipping.
