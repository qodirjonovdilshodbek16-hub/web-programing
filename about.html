About the project

A small store with big ideas.

TechNest is our final project for the Web Programming course. It is a demo online store where you can browse gadgets, search and filter products, build a cart and send a message through the contact form.

The goal was to practise clean HTML structure, responsive CSS and plain JavaScript without any frameworks, and to publish the result with Git and GitHub Pages.

What's inside

  • Five linked pages with a shared menu
  • Product search, category filter and sorting
  • Cart saved in the browser (localStorage)
  • Contact form with live validation
  • Light and dark theme
  • Responsive layout and keyboard-friendly controls
